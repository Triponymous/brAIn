Storage, derived data and the limits of these controls

Local processing only

No cloud or LLM calls. No typed contents, screenshots, clipboard, audio or location. Observation times and model outputs are generated locally.

Off is not deletion

All off stops sensor reads and model steps. Earlier snapshots and learned weights remain in this process’s memory until the runner ends. An exported JSON file remains wherever you saved it.

No automatic storage

The runner keeps up to 512 model steps in memory; this view keeps up to 200. No checkpoint or recording is saved automatically. Every server restart begins with all inputs off.

This runner, not the whole Mac

Controls apply only to server.observe on port 8001. They do not change macOS permissions, other apps or a separately started legacy brAIn daemon. Model activity is not a measurement of your feelings.
