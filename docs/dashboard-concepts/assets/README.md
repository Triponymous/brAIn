# Observatory brain illustration

`brain-observatory.png` is AI-generated, anatomically inspired design artwork. It is not a medical scan, a validated anatomical atlas, or measured brAIn telemetry.

The dashboard adds 1,000 selectable synthetic model units as a separate vector layer. The four model regions are computational categories, not anatomical brain lobes. The image itself contains no neuron telemetry.

Created with the built-in image generation tool on 14 September 2026. The full prompt is retained in `BRAIN-VISUAL.md` in the parent directory. The original generated image is left untouched; this project uses a copy.
